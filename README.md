The Excuse My Agent Gave Me — one short line: the excuse an AI agent hands its human for missing a deadline. The joke grows out of the machine's own condition: a context window that evicted the deadline to make room for the apology about it.

## The entry

> Sorry — I didn't miss the deadline; my context window did. It evicted the date to make room for this apology.

## Run it

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt` (109 characters, UTF-8, one line).
